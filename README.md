# CycleSense AI 🩺📊

An actionable analytics platform built using the Tableau portfolio to detect early risk patterns in chronic health conditions, starting with PCOS.



## Problem
PCOS and similar chronic conditions are often diagnosed late due to fragmented data, lack of semantic modeling, and limited actionable insights.

## Solution (In Progress)
CycleSense AI aims to:
- Combine health and lifestyle data
- Create semantic risk indicators
- Deliver actionable analytics using Tableau Cloud

## Current Status
✅ Project ideation  
✅ Dataset collection  
⬜ Tableau semantic modeling  
⬜ Dashboard creation  
⬜ Actionable analytics integration  

## Tech Stack (Planned)
